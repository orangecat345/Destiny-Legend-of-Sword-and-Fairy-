## 剧本入库方式

可先提供已有的剧本文本文件，再在此目录整理。第三方链接中的完整剧本不直接整篇转载；在没有所提供的正文时，先保留来源记录，取得内容后可整理摘要和场景索引。

收到剧本文件后：

1. 记录提供方式、原文件名、文件哈希和版本信息；保留原有标题、段落、章节与作者署名。
2. 单独核对缺章、缺页、重复、楼层顺序和图片中的文字；无法确认的部分明确标注。
3. 将原稿与整理稿、新增设计分开；文字校订或 OCR 修正附记录，不静默改写作者内容。
4. 为每个场景保留章节、页码或楼层定位，再建立人物、地点、事件和续作任务索引。

开发顺序见[原版分析与续作开发流程](../original-analysis.md)。
