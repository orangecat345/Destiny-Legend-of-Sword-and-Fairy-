温若水等人回到蜀山。蜀山已经变成一座魔剑之山。打败了镇守蜀山的魔化天罡剑阵，众人破了阵眼。但是蜀山已经不适宜人类生存，众人只能放弃。

<a name="u109"></a>

回到仙灵岛，结界已破。众人在外围遇到了韩无双，战斗一场后韩无双逃入岛内。原来她怀着妒忌之心想来暗杀王飞霞，但是被守卫在岛内的李剑灵幻影杀死。众人奋力打败李剑灵的幻影，救出了被封印的王飞霞，但王飞霞仍然昏睡不醒。

<a name="u120"></a>

拥有了历代记忆的李剑灵，不但实力突飞猛进，而他比起赢伯益来要走的更远，他想要控制真正的九天神曜仪！

<a name="u121"></a>

遥神君请求王飞霞一定要阻止李剑灵。最后遥神君将自己的神格赋予了王飞霞，王飞霞成为真正的高位神，霞神君。

众人回到据点，整理行装，端正心态，做足一切准备，向西方昆仑神界前进！

神誓达成。野生神“月灵”诞生，但众人已走远，无人知晓。

<a name="u163"></a>

第六重天，由昆仑山神界的守卫神兽，大开明兽守卫。在李剑灵的影响下，大开明兽已经迷蒙了双眼，不辨了是非。众人艰险过关。

<a name="u166"></a>

第八重天，守卫者是天魔界的魔将震远，他曾经是上古时赢王的忠实护卫。如今，他也忠实的守卫着自己认为的赢王化身——李剑灵。

<a name="u167"></a>

第九重天界，众人终于见到了即将进入九天神曜仪的核心天柱之中的李剑灵。王飞霞试图阻止他，但是，尽管王飞霞已经成神并且一路保存实力，在李剑灵的力量下竟然丝毫无用。此时的李剑灵，只是获得了一小部分的天柱力量而已。最终李剑灵还是成功的进入天柱，在众人的惊愕中，李剑灵说出了一切的真相。

<a name="u168"></a>

当初，天魔袭击蜀山的事件，完全是一场神界的阴谋。

<a name="u169"></a>

那个天魔名为龙邪，是天魔界魔尊御天手下的新兴之秀，有问鼎魔尊之位的潜力，因此颇受众魔排挤。龙邪一怒之下向神界投诚，而神界交给他的任务，就是诱使李剑灵进入锁妖塔并封印他。

<a name="u170"></a>

被封印的李剑灵奋力想冲出封印，但毫无可能。突然一天，李剑灵发现自己获得了自由，但是很快，他发现自由的不是自己的身体，而是……重聚中的无相天妖！

<a name="u171"></a>

李剑灵想起了当年，无相天妖说“我们曾是一体”，当时只当那是胡说。但是如今，比起已被毁灭的无相天妖竟然重生，李剑灵更震惊于他能够在自己的身体与无相天妖之间自由转换，而无视一切封印、结界与空间阻隔的事实。难道武神与无相天妖真的有某种关联，那么杀死自己姐姐的究竟是什么东西？

<a name="u172"></a>

虽然震惊，但李剑灵很快接受并利用了这个事实。此时，通过与李剑灵交手，龙邪觉醒了自己作为魔皇“藜渊”之一魂的觉悟。附身于无相天妖的李剑灵，与觉醒了魔皇之魂的龙邪，二人联合了对赢王心存愧疚的魔尊殷熇，竟然弄到了魔皇五兵之四。李剑灵发现了魔皇甲能令穿戴者丧失神智，便诱骗魔尊御天穿上，使原本阴狠狡诈的御天沦为傀儡。而无相天妖化的李剑灵与龙邪轮流扮演了“黑武士”这一角色，有时两人也一同上阵，比如潜入神树吸取灵力那次，伏魔网能够压制龙邪，但压制不了化身为无相天妖的李剑灵。李剑灵更使用碎空刀，打破幽界与明世的界限，解放出幽煌神将。而他们所做的一切，就是为了搅乱乾坤。当神界不得不应对来自幽神的威胁时，也就顾不上他们了。李剑灵的最终目的，就是要掌握九天神曜仪，改变女娲后人悲剧的宿命。

<a name="u173"></a>

如今，李剑灵成功了。

<a name="u174"></a>

真的吗？

<a name="u175"></a>

李剑灵获得了力量，现在的他，能够轻易令神界颠覆，令天地翻转，令生者灭亡，令死者复生。但是，这一切又都有什么意义呢？

<a name="u176"></a>

身处天柱，李剑灵见到了完全不同的世界。现在他知道什么是逆天而行了。天意，并不是逆反者一厢情愿认为的神界对人间的压迫，而是整个六界，甚至是整个宇宙，八荒六合，古往今来，所有意志交织而成的因果之网。而女娲后人的宿命，则静静的穿插于网中，源头直至太古。李剑灵看到了自己，看到了武神与无相天妖的由来，看到了那个在太古时代，对三皇诅咒的原身。武神的存在本就是矛盾的，自己所做的一切，也是毫无意义的。

<a name="u177"></a>

但是，已经无法收手了。九天神曜仪需要一个核心，能够掌握这个世界的核心。李剑灵无法离开。但是，他已经到了尽头。神性、人性、以及因附身于无相天妖而不断增长的魔性，撕裂着他，他越来越不能认清自己。李剑灵狂笑着，做出了出乎所有人意料的抉择。

<a name="u178"></a>

李剑灵突然消失了，就像他从未存在过一样。

<a name="u179"></a>

王飞霞追入天柱，却再也见不到李剑灵。众人来不及从震惊与悲伤中回复，突然，正与神界战斗的龙邪感到异常，跨越空间之门来到了众人面前。龙邪大骂李剑灵没有遵守承诺颠覆神界，并将怒火撒向众人。最后一战开始了！

<a name="u180"></a>

在王飞霞的帮助下，众人尽全力压制了龙邪。但暴怒的龙邪怒吼：六界兵主，战神藜渊，现吾真身！化身为貌似昔日魔皇的巨大姿态。全盛状态的龙邪，完全无视了众人的攻击：叶寒枫的剑神如雨点般打在龙邪身上，也如雨点般破碎飞溅；花碧瑶试图用藤蔓阻碍龙邪的行动，却被龙邪反手一抓一挥，身躯被震得粉碎，幸得叶寒枫护住了她的根；温若水被气浪击中头部，昏了过去；李心莲全力一击不能破防，反而宝剑断裂，提剑再战时却发现右臂已经骨折。

<a name="u181"></a>

已经不将众人放在眼里的龙邪，使用巨大的兵器砍伐天柱，虽然有王飞霞在天柱之内竭力修补，但仍造成了巨大的破坏，绝望中，李心莲不计一切的冲向龙邪，她左手佩戴的“炼魔五锋”飞速蔓延，变成了覆盖半身的甲胄和利刃，龙邪转身给李心莲最后一击，但半身已然被“炼魔五锋”覆盖的李心莲却形同鬼魅，闪现到龙邪身下，给了他致命一击！

<a name="u182"></a>

龙邪被消灭了，但是，这样下去，又会出现上古时天柱山倒的惨象。王飞霞用自己的神力，集合五灵珠的力量，已经升级成神灵的六御灵的力量，五灵轮的力量，修补维持了天柱。但是，作为代价，她不能再离开这里一步。

<a name="u183"></a>

王飞霞传送走了众人与哭泣的李心莲，封闭了昆仑九重天界，作为世界的守护者，她孤独的留在了那里。

<a name="u184"></a>

某种程度上，李剑灵的心愿达成了。因为人世间再也没有女娲后人了，而作为天柱守护者的，最后的女娲后人——王飞霞，再也不会被女娲的宿命烦扰了。

<a name="u185"></a>

昆仑山下，李心莲对天发誓，一定要寻回父亲，重回昆仑山，重登九重天……

<a name="u186"></a>

天问篇，全剧终。
