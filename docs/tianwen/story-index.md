## 先改编的流程

现存文本中，黑客栈 → 救小小 → 见费无极／燕别古／韩无双 → 上山见炎风，是一条有明确来源、人员稳定的短流程，可先做队伍、调查、非致命战斗和过场的验证。它可以沿用 R-A 的相遇候选作为可跳过序幕，避免一开始就依赖尚未定案的生父关系或傀儡术。

后续再做“和谈 → 入塔救父 → 瀚海梦”作为恢复稿的首条验证线。制作数据中应同时保留剧情依据和恢复版本；源自 U 编号的情节与源自 R 编号的情节可单独替换。现有《回响之门》是另一套新增规则原型，本轮没有把这份剧本声称为已经实现的游戏。
